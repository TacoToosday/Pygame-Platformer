# Pygame Platformer

A platformer game built with Python and Pygame.

## Getting Started

### Prerequisites

- Python 3.10 or newer, preferably Python 3.14.2
- Pygame

### Installation

Clone the repository and install the project dependency:

```bash
git clone https://github.com/TacoToosday/Pygame-Platformer.git
cd Pygame-Platformer
python -m pip install pygame
```

### Running the Game

Once the game entry point is available, run it with:

```bash
python main.py
```
